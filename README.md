# ✨ GrayQuest Fintech Onboarding Wizard

A premium, high-fidelity digital onboarding experience designed with a sleek **"Quiet Luxury"** aesthetic. This wizard guides parents seamlessly through personal information inputs, OTP verification, profile analysis, and credit limit provisioning with native theme customization.

🎨 **Live Production App:** [fintech-onboarding-wizard.vercel.app](https://fintech-onboarding-wizard.vercel.app)

---

## 🌟 Key Features

*   **⚡ "Quiet Luxury" Aesthetics:** Modern minimalist typography, custom HSL glassmorphism, and responsive card overlays built to stun on any viewport.
*   **🌓 Native Light & Dark Themes:** Smooth light-to-dark switching using CSS variables (`next-themes`) that dynamically update layouts on the fly.
*   **🪄 Immersive Step Transitions:** Framer Motion orchestration using customized 3D-like blur and horizontal slide animations.
*   **🛡️ Dynamic Non-intrusive Validation:** Interactive form feedback highlighting exactly what's missing (e.g. "Select a school" or "Accept terms") right below the main action button.
*   **📊 Animated Radar Scanner:** A high-end radial sweep radar animation evaluating credit worthiness in real-time.
*   **📱 Optimized OTP UX:** Flex-oriented responsive OTP boxes scaled to fit perfectly down to `320px` width displays, featuring instant key navigation and cursor auto-focus.

---

## 🛠️ Tech Stack & Architecture

*   **Framework:** [Next.js](https://nextjs.org/) (App Router, built for blazing fast server-side optimization).
*   **Animations:** [Framer Motion](https://www.framer.com/motion/) (orchestrating all spring-based gestures and steps).
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS Tokens (native fluid styling).
*   **Icons:** [Lucide React](https://lucide.dev/) (elegant outline iconography).

## 🚀 Local Setup

To run the project locally on your machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Ayushmishra112/Fintech-onboarding-pipeline.git
    cd Fintech-onboarding-pipeline
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) in your browser to experience the wizard!
